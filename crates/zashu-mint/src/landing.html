Cashu + Zashu: Better Together

Zashu never replaces Cashu's fast BDHKE tokens. Both run side-by-side in one mint sharing one Lightning backend and one unified NUTZ-1 Proof-of-Solvency.

STEP 1 · STANDARD CASHU

Fast BDHKE Spending

Receive & spend standard power-of-2 Cashu proofs (128 + 8 + 1 sats) in <50ms on any mobile phone.

STEP 2 · /v1/zk/shield

Zero-Fee Shielding

Merge legacy Cashu tokens into 1 single Zashu note (137 sats) inside the same mint with zero Lightning fees.

STEP 3 · SHIELDED ECASH

Stealth & Smart Policies

Pay offline friends via zsp1... stealth keys (double-spend-proof) or lock funds with hidden HTLCs & multisig.

STEP 4 · /v1/zk/unshield

Unshield Anywhere

Unshield back to standard Cashu tokens or melt directly over Lightning—interoperable with every existing Cashu wallet.

Standard Cashu (BDHKE)

  • Speed: Sub-50ms, stateless bearer tokens.
  • Amounts: Power-of-2 splits (128+8+1) leak approximate size.
  • Policies: NUT-10/11 P2PK & HTLCs visible to the mint.
  • Offline Receive: Receiver must race online to /v1/swap.
  • Solvency: Users trust the mint not to run fractional reserve.

What Zashu Adds to Cashu

  • Verifiable Solvency (NUTZ-1): Drop-in sidecar proving liabilities ≤ L1 reserves for all Cashu + Zashu tokens.
  • Arbitrary Amounts (NUTZ-2): Hidden values in 1 Pedersen commitment—no power-of-2 splitting.
  • Offline-Safe Stealth (NUTZ-3): Double-spend-proof zsp1... receives + oblivious witness sync.
  • Hidden Predicates (NUTZ-4): Private P2PK, Multisig, Timelocks & Cross-Mint Atomic Swaps.

How Zashu Works Under the Hood

Four clean cryptographic layers built on Halo 2 (Pasta/IPA, no trusted setup) and Tachyon accumulators.

LAYER 1 · NUTZ-1 SOLVENCY

Folded Mint Accounting

Every mint, swap, and melt updates total_liabilities and folds into one 16 KB proof verified against Bitcoin Taproot UTXOs in ~1 ms.

LAYER 2 · NUTZ-2 UNIFIED k=13

Single-Proof Note Swaps

One Halo 2 proof enforces 32-level Poseidon Merkle membership, 64-bit range checks, and Pedersen value balance without revealing amounts.

LAYER 3 · TACHYON PRUNING

Bounded Mint Storage

Indexed nullifier accumulators block double-spends while pruning old epochs (~49.6% node reduction over 10k spends).

LAYER 4 · NUTZ-3 & 4

Oblivious Sync & Predicates

Wallets refresh Merkle witnesses via GET /v1/zk/sync without leaking note indices, and run hidden HTLCs across mints.
